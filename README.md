House Price Analysis

Exploratory data analysis of residential property prices using Python.

Project Overview

This project focuses on exploring and understanding a residential housing dataset and analyzing the factors associated with house sale prices.

The project is being developed step by step, starting with exploratory data analysis and data understanding.

Tools & Libraries

- Python
- Pandas
- NumPy
- Jupyter Notebook

Current Progress

- Initial dataset inspection
- Data type analysis
- Missing-value analysis
- Sale price distribution analysis
- Quantile analysis
- Investigation of extreme values
- Exploration of important housing features, including:
  - Year Built
  - Gr Liv Area
  - Overall Quality
  - Neighborhood

🚧 Work in Progress
